# SixEyes — Client Base for Minecraft 26.3
**SixEyes** is a clean, lightweight, and open-source client base for Minecraft **26.3**, built as a solid foundation for creating your own custom utility mod or visual client.

## Features
* **Rendering:** Dual backend support (**Vulkan** & **OpenGL**)
* **ClickGUI:** Clean DropDown interface
* **Settings System:** `Boolean`, `Mode`, `MultiMode`, `Number`, and `ColorPicker`
* **Event System:** Fast and lightweight event bus (`Flora`)
* **Example Modules:** Includes `InventoryMove` and core rendering utilities out of the box

## Disclaimer
This project is provided strictly as an educational base and template. Using third-party modifications may violate the terms of service of some Minecraft servers. Use at your own risk.
